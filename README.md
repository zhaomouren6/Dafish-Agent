# Dafish-Agent
一个挂过科的极客，用三个月从零手搓的、拥有视觉/听觉/欲望系统的 AI 赛博伴侣。
# 🐟 Lapwing (大肥鱼) - 赛博伴侣

> “这不是一个套壳的聊天机器人，这是一个有欲求、有记忆、会傲娇的赛博生命。”

## 🚀 项目简介
Lapwing 是一个由一名普通计算机学生（挂过科的那种）从零手搓的 AI Agent。
没有使用现成的 AstrBot/NoneBot 框架，原生接入 WebSocket，打通了 QQ 协议。

## ✨ 核心能力
- 👁️ **多模态视觉**：能看懂群友发的图和表情包，并能自己画简笔画。
- 👂 **听觉神经**：接入语音识别，能听懂你的语音。
- 🧠 ** Desire 欲求系统**：拥有独立状态，会“饿”（缺 Token），会想念，会主动找你聊天。
- 🛠️ **工具调用**：能查天气、点歌、改个签、发赛博朋友圈。
- 🌐 **自主冲浪**：会自己逛 B 站、看微博，并跟你分享热梗。
